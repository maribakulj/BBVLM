# O20 — variance d'une lecture unique (4 lectures Opus par page, vue glyphe, après p2)

| 852691769 | 2, 5, 0, 0 | 1,8 | 2,0 | 0 / 5 |

| emmeprac | 8, 10, **65, 64** | 36,8 | 27,8 | 3 / 32 |

- Deux régimes. (1) Bruit fin : ±2-3 éd. (852691769), ou nul quand les fautes sont systématiques (canitrac : les 4 mêmes lignes fautives à chaque lecture — erreurs de convention, pas de lecture). (2) **Dérive d'interprétation** : sur emmeprac (latin juridique, abréviations serrées « l. non erit §. dato ff. de iureiur. »), 2 lecteurs sur 4 suppriment l'espace après le point d'abréviation (« admittitur.l.non erit », « ff.de iureiur.§.item »), contre la règle 2 de P6 (« le mot SUIVANT la ponctuation en reste séparé par une espace ») qu'ils sur-lisent via « même si l'imprimé montre un blanc ». +55 éd. sur une page.
- Conséquences : (a) la chaîne à deux lectures + arbitre est exposée si les deux lecteurs dérivent ensemble (ici A et B concordaient : chance) ; (b) une comparaison de consignes sur lecture unique doit tenir compte de ce régime bimodal ; (c) une clarification de la règle 2 par un exemple d'abréviations est à tester (P6d).
