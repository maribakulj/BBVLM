# A02 — audit aveugle du verdict hackherz l006 (déclenché par R3/R4)

| source | texte |
|---|---|
| VT distribuée | 2. Cor. XII 3. 4. |
| verdict adjugé (2 arbitres, O10, avant P6d) | 2.Cor.XII.3.4 |
| relecteur aveugle 1 (consigne P6e, sans candidats) | 2. Cor. XII. 3. 4 |
| relecteur aveugle 2 | 2. Cor. XII. 3. 4 |
| lecture finale après R4 | 2. Cor. XII. 3. 4 |

- Règle A01 (annulation si les deux relecteurs concordent avec la VT distribuée) : **non remplie** → verdict maintenu → R3/R4 restent rejetées au critère figé.
- Constat : les deux relecteurs aveugles écrivent exactement la forme de R4 (points tels qu'imprimés, blancs selon P6d) ; le verdict adjugé garde les blancs de l'imprimé serré, antérieur à la règle P6d. La référence adjugée n'est donc pas homogène avec la consigne actuelle sur les blancs après un point d'abréviation.
- Piste (à décider) : une révision de convention de la référence adjugée (blancs P6d appliqués aux verdicts antérieurs) serait un changement de mesure, pas de chaîne ; à pré-enregistrer à part si on le fait.
