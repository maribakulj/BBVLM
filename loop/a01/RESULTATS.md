# A01 — résultats (audit aveugle de 97 verdicts d'adjudication, 12 œuvres)

2 relecteurs Opus indépendants par lot (4 lots), sans candidats ni référence, consigne P6e pour les conventions.

| issue (règle figée) | lignes | part |
|---|---|---|
| confirmé (les deux relecteurs = ligne adjugée) | 56 | 58 % |
| indécis (relecteurs en désaccord, ou ni VT ni adjugée) | 33 | 34 % |
| **annulé** (les deux relecteurs = VT distribuée) | **8** | **8,2 %** |

- Hypothèse (≤ 5 % annulés) : **réfutée** (8,2 %).
- Les 8 annulés : 6 blancs (« ihmviel », « dißLeben … v on », « traher e », « lengſt(darumb », « gentis,quæ … &ſpecies »), 1 lettre (« ſteis » contre « ſtets », baurodwe), 1 renvoi de colonne rattaché à la mauvaise ligne (« eſt u- », 852691769), et geomeikud « drůdden » contre « druͤdden » (u + e suscrit). Les arbitres d'adjudication, quand ils concordent contre la VT, se trompent donc surtout sur les **blancs** et sur les signes suscrits — les mêmes points faibles que les lecteurs.
- Effet sur la mesure (50 pages, texte final, vue glyphe, contre l'adjugée) : total **274 → 283** éd. ; pages à 0 : **12 → 10** (baltdiss 0 → 1, 852691769 0 → 3) ; ≤ 1 : 22 → 19 ; ≤ 2 : 29 → 25 ; médiane 2 inchangée ; pire page inchangée (extraudeu 43), buchdas 37 → 38 ; goclprop 9 → 7 (annulation favorable à la chaîne).
- Les 33 indécis restent tels quels (règle A2 inchangée) ; beaucoup relèvent de conventions (J/I, uͤ/ů/ü, ⸗/-) où les relecteurs sans candidats ne suivent pas la VT.
- Conséquence : les « 0 % » antérieurs étaient optimistes d'environ 3 % des éd. ; l'audit aveugle à deux relecteurs devient une étape obligatoire de toute adjudication (lignes dont la référence change), avant publication d'un chiffre.
