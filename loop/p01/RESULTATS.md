# P01 — résultats (55 pages O07-O25, référence adjugée auditée, vue glyphe)

| politique | éditions |
|---|---|
| lecture A seule | 386 |
| sélective (seconde lecture sur le tiers au signal le plus haut) | 365 |
| complète (2 lectures + arbitre partout) | 299 |

- Part du gain gardée par la politique sélective : **24 %** (critère : ≥ 80 %) → **P01 réfutée**.
- Spearman signal / erreurs de A : ρ = 0,31 (p = 0,02) ; signal / gain de la seconde lecture : ρ = −0,05 (p = 0,71).
- Lecture : le désaccord avec Tesseract mesure la difficulté de la page pour Tesseract (titres, chansons, antiqua italique), pas l'endroit où une seconde lecture VLM corrige la première (geomeikud −14, buchdas, brieetli se retrouvent en haut, mais hermhyst, eberbrev, canitrac aussi, sans gain).
- Conséquence : la seconde lecture reste systématique en mode qualité (−23 % d'éditions sur 55 pages ; −33 % sur les 12 pages neuves O23-O25) ; aucun signal a priori gratuit retenu.
