- Hypothèse (P6e au moins aussi bien que O16-O18 sur pages ordinaires) : **tenue contre la référence adjugée** (0/1/3/1, médiane 1, pire 3 éd. = 0,17 %). CRITERE 1/4 (O18 : 2/4) ; pire ALTO caladr 0,834.
- **Mais** contre la VT distribuée caladr compte 18 éd., et l'examen montre que l'adjudication a absorbé une vraie omission des lecteurs : l'imprimé porte « q́ » **avec** le crochet ꝫ sur la hampe (vérifié sur le recadrage l001 : « formamq́ » avec le « 3 » sous le q), la VT le code U+F50D (= q́ꝫ), les deux lectures écrivent « q́ » seul et les deux arbitres ont validé « q́ » (8 éd. sur 7 lignes). Le reste de caladr est de vraies fautes de VT corrigées (« Viddro », « Memoresea », « ſcilicetouis », « nu bila », « Vinclapedi »…) ou du codage (ß de l'italique = ſs, 2 éd.).
- abdipre : la VT elle-même code l'abréviation « -que » tantôt « qꝫ », tantôt « q; » (7 « q; » dans les 76 VT préparées, ferrepit, goclprop, AyrmThes) : équivalence de codage, non faute.
- Recherche caladr 0,886 : les mêmes « q́ꝫ » (vue recherche : « formamq́ꝫ » ≠ « formamq ») et ß/ſs.
- Lignes lues non placées : 2 sur 121 (BiedBern).
