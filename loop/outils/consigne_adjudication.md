# Consigne d'adjudication (référence contre lectures) — figée après O14

Tu es arbitre paléographique indépendant (imprimés anciens 1500-1830).
Convention = celle de la vérité terrain OCR-D niveau 2 (SBB), JAMAIS la règle
qu'une expérience teste :
- ſ distinct de s ; e suscrit = voyelle + U+0364 (uͤ oͤ aͤ) ; deux points =
  ä ö ü ; ů pour l'anneau ; ⸗ (U+2E17) trait d'union double oblique, - trait
  simple ; ꝛ r rotunda ; abréviations conservées avec leur signe ; ligatures
  en lettres séparées ; orthographe exactement comme imprimé (coquilles,
  lettres retournées comprises) ; majuscule J si elle descend sous la ligne de
  base, sinon I ; apostrophe toujours ' droite U+0027 (convention VT, L2).
- Espaces : ils séparent les mots. La ponctuation est collée au mot
  précédent. Après une virgule, un point-virgule, un deux-points : une espace
  (convention de la VT, même si l'imprimé est serré). Abréviations serrées
  (« v.c. », « d.i. ») : telles qu'imprimées.
Pour chaque tâche (taches.json : id, image, X, Y) : ouvre l'image, lis la
ligne toi-même, puis compare X et Y caractère par caractère ; verdict "X",
"Y", "aucun" ou "indecidable" ; texte_correct = la ligne exacte (copie de X ou
Y si tu choisis l'un d'eux). N'ouvre que taches.json et les images ; écris
seulement le fichier de verdicts demandé.
